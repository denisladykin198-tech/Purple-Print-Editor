# Purple Print

Воксельный редактор объектов для 3D-игры. Принцип его работы аналогичен классическому черчению. Пользователь создаёт силуэты в трёх проекциях и алгоритм собирает из них 3D-модель. Редактор позволяет создавать слоты для модули прямо на 3D модели, с возможностью написания для них скриптов и экспортируешь в формат, который читает движок.

Стек: Bevy 0.13, egui, Rhai.

## Что умеет

- Редактирование вокселей через 2D-холсты (Front / Top / Side) и генерация 3D пересечением силуэтов
- Инструменты: кисть, линия, прямоугольник, эллипс, заливка, шум, сглаживание. Симметрия по X/Y.
- Импорт готового фото в силуэт (порог, поворот, зеркало, режимы наложения)
- Модульная сборка: фреймы, слоты, варианты модулей, pivot, превью размещений
- Скриптовые зоны в 3D и Rhai-скрипты (на фрейм и на зону)
- Сглаживание сетки (Median, Six-neighbor, Gaussian, двухпроходный median)
- Цветовые схемы для воксельного меша
- Экспорт в `.mpp` + автоген `*.object.rhai` и скриптов зон

## Стадии

1. **Воксели** — 2D-холсты, инструменты, генерация 3D, импорт фото, список модулей
2. **Слоты** — точки крепления на модели, варианты модулей, привязка к зонам
3. **Скрипты** — зоны поведения + Rhai-редактор
4. **Сглаживание** — фильтры по воксельной сетке
5. **Текстуры** — vertex-color схемы
6. **Экспорт** — метаданные, валидация, запись в `assets/objects`, импорт `.mpp`

Список модулей доступен из первой стадии (боковая панель).

## Планы развития:

- Реализовать полноценный скриптинг модулей.
- Создать алгоритм превращающий воксельную сетку в классические полигоны.
- Создать систему auto-LOD, автоматически создающую несколько упрощённых level of details моделей на основе изначальной.
